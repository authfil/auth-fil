# Security Policy

## Supported versions

Authfil is in early development and hasn't made a stable release yet. Security fixes go to the `main` branch.

## Reporting a vulnerability

**Please don't open a public issue for security problems.**

Report them privately through GitHub's [private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability) (the **Security → Report a vulnerability** tab on this repository).

Please include:

- the affected component (core, crypto, or a specific adapter) and version or commit;
- a description of the issue and its impact;
- steps to reproduce, or a proof of concept.

We will acknowledge your report, keep you updated while we work on a fix, and credit you in the advisory unless you'd rather stay anonymous. We'll request a CVE for confirmed vulnerabilities where appropriate.
