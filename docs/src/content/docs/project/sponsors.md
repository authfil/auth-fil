Authloom doesn't have any sponsors yet.

## What sponsorship pays for

For an auth library, trust is the product. Sponsorship goes mainly towards the work that builds trust:

- **Independent security audits** of the core and each adapter.
- **Conformance certification**, such as the OpenID Foundation certification for provider mode.
- **Test tenants** for enterprise identity providers such as Okta and Microsoft Entra ID, used to test SAML and SCIM.
- **Maintainer time** for security response, reviews and releases.

## Becoming a sponsor

Sponsorship options aren't set up yet. If you or your organisation would like to support the project, please open an issue on the repository and we'll get in touch.
