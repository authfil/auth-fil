:::caution[Not ready yet]
This adapter is scaffolded in `adapters/rust/` but doesn't expose an API yet. Check the [roadmap](../../project/roadmap/) for when it lands.
:::

The Rust adapter is an idiomatic SDK over `authfil-core` for Rust apps, for example ones built with Axum or Actix. Unlike the other adapters, it has no FFI boundary to cross: it wraps the core's ports in an ergonomic Rust API. Like every adapter, it makes no security decisions of its own.

## API reference

The Rust API reference is generated by rustdoc: see [Rust (rustdoc)](../../api/rust/authfil_core/).
