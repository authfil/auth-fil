---
title: Architecture decisions
description: How significant design decisions are recorded.
---

Significant design decisions, one per file, numbered in order: `0001-sans-io-core.md`, `0002-...`.

Each ADR has four sections: **Context** (the problem), **Decision** (what we chose), **Alternatives** (what we rejected and why) and **Consequences** (what this makes easier or harder). ADRs are never edited after they're accepted. A later ADR replaces an earlier one instead.
